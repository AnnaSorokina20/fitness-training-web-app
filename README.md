# Веб-застосунок для організації фітнес-тренувань

## Опис проєкту

Веб-застосунок для організації фітнес-тренувань — це система, призначена для перегляду, пошуку, фільтрації та збереження тренувального контенту. Система надає користувачам доступ до каталогу вправ і тренувальних комплексів, дозволяє формувати персональний плейлист, залишати коментарі та оцінки, а також переглядати детальну інформацію про вправи.

Проєкт розробляється в межах бакалаврської кваліфікаційної роботи зі спеціальності 121 «Інженерія програмного забезпечення».

## Мета проєкту

Метою проєкту є розроблення веб-застосунку для тренажерного залу, який дозволяє користувачам швидко знаходити вправи та тренувальні комплекси, зберігати корисний контент у персональному плейлисті, створювати власні тренувальні плани, а також забезпечує тренерам і адміністраторам інструменти для керування контентом та користувачами.

Застосунок має допомогти відвідувачам тренажерного залу або користувачам, які тренуються самостійно, отримати зручний доступ до структурованої бази вправ, а тренерам — спростити процес публікації та оновлення тренувальних матеріалів.

## Основні функції

- перегляд каталогу вправ;
- перегляд каталогу тренувальних комплексів;
- пошук вправ за ключовими словами;
- фільтрація вправ за складністю, обладнанням, типом тренування та м’язовою групою;
- перегляд детальної сторінки вправи з описом, параметрами та медіаматеріалами;
- реєстрація та авторизація користувачів;
- розмежування доступу за ролями;
- додавання вправ і тренувальних комплексів до персонального плейлиста;
- перегляд і видалення елементів із плейлиста;
- залишення коментарів до вправ;
- виставлення оцінок вправам;
- створення та редагування вправ тренером;
- створення тренувальних комплексів;
- модерація контенту перед публікацією;
- керування користувачами адміністратором;
- журналювання адміністративних дій;
- підтримка soft delete для безпечного видалення даних;
- аудит створення, оновлення та видалення записів;
- збереження історії змін основних сутностей.

## Ролі користувачів

У системі передбачено такі ролі:

- **Гість** — може переглядати каталог вправ і сторінки вправ без авторизації.
- **Користувач** — може зберігати вправи й комплекси у плейлист, залишати коментарі та оцінки.
- **Тренер** — може створювати, редагувати та надсилати на модерацію вправи й тренувальні комплекси.
- **Адміністратор** — може керувати користувачами, ролями, модерацією контенту та переглядати журнал адміністративних дій.

## Методологія розробки

Для організації розробки використовується підхід **Agile/Scrum з елементами TDD**. Робота над проєктом поділяється на короткі ітерації, кожна з яких має окрему мету та конкретний результат.

Елементи TDD використовуються для забезпечення перевірюваності функціональності: для основних модулів системи визначаються очікувані результати роботи та критерії перевірки.
